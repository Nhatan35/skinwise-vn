# SkinWise VN CV Project Summary

## Resume Bullet Version

- Built SkinWise VN, an educational skincare tracking MVP using the repository's confirmed web application stack.
- Designed core user flows for skin profile setup, product comparison, product matching, routine tracking, journal entries, insights, and settings/data export where supported by the MVP.
- Defined MVP scope, safety boundaries, demo script, screenshot checklist, release checklist, and portfolio evidence documentation.
- Positioned the product as a non-medical educational tracking tool, avoiding diagnosis, treatment, image analysis, face analysis, and skin scoring claims.

## Interview Explanation Version

SkinWise VN is an educational skincare tracking MVP designed to help users organize their skincare profile, compare skincare products, track routines, record journal entries, and review personal insights. The project focuses on a practical MVP journey instead of adding marketplace, checkout, payment, reviews, notifications, image analysis, face analysis, skin scoring, or medical recommendation features.

From a BA and product-thinking perspective, the project emphasizes MVP scope control, clear in-scope and out-of-scope boundaries, safety-aware wording, feature traceability, release evidence, and demo readiness. The app is positioned as an educational tracking and decision-support tool, not a medical diagnosis tool or dermatologist replacement.

## GitHub / Portfolio Description Version

SkinWise VN is an educational skincare tracking MVP that helps users manage their skin profile, compare skincare products, track daily routines, record journal entries, and review personal insights. The project focuses on MVP scope control, safe non-medical positioning, and portfolio-ready documentation.
